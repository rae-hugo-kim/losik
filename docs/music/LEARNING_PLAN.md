# '좋은 명령'을 위한 학습 계획 (4주) — v2

> 전제 (정정됨): 학습자의 현재 자산은 **정확한 귀** (밸런스·반복·이물감을 잡아내는 관측력 — 세션에서 3연속 적중 실측).
> 부족한 것은 이론이 아니라 **관측을 전달하는 형식**과 **최소 어휘**.
> 핵심 원리: **이론을 몰라도 상급 명령이 가능하다** — 코드진행을 말할 줄 몰라도 "이 곡의 코러스처럼"이라고 지목하면 같은 명령이다. 화성 이론은 부록(선택)으로.

## 역할 분담 (이 시스템의 계약)

- **사용자**: 정확히 듣고, 지목하고, 레퍼런스를 가리킨다
- **에이전트**: 그걸 진행·편성·수치 스펙으로 번역해 **작곡 전에 보여주고 확인받는다** (PROMPT_GUIDELINES §1)
- → 친구가 해줬던 "스펙 작성" 역할은 이 확인 루프가 대신한다. 친구 없이 돌아가는 구조.

## 1주차 — 지금 잘하는 것에 형식 입히기

**배울 것**: 피드백 3문장 형식 "**관측 → 추정(선택) → 지시**" + 부위 단어 6개만: **킥 / 스네어 / 햇 / 베이스 / 멜로디 / 반주(배경)**
- 추정이 어려우면 생략 가능. "관측 + 어디인지"만으로 충분: "코러스에서 멜로디가 반주에 묻힌다"
**과제**: 기존 바운스 3곡을 듣고 곡마다 피드백 3문장 1건씩 작성 (형용사 금지 — "밋밋해" 대신 "무엇이 안 들리는지/계속 똑같은지")
**합격선**: 부위 단어를 쓴 피드백 3건 — 이미 거의 하고 있으므로 1주면 체화

## 2주차 — 부위 분리 청취 (귀 훈련의 본체)

**배울 것**: 리듬 단어 5개만: **빠르기(BPM 감) / 쿵쿵 네 번(4온플로어) / 반 박자 느긋(하프타임) / 착 붙는 박수(스네어 2·4) / 잘게 쪼개기(16분 햇)**
**과제**: 좋아하는 곡 2곡을 "킥만 3번 → 스네어만 3번 → 햇만 3번" 회전 청취. 들으면서 손으로 패턴 두드리기
**명령 실습**: 기존 스케치 1곡의 드럼을 부위 지목으로 수정 의뢰 ("햇이 너무 기계 같다, 사람이 치는 느낌으로" — 이 정도로 충분, 스윙/지터 번역은 에이전트 몫)
**합격선**: 곡을 듣고 "킥이 어디를 치는지" 입으로 흉내낼 수 있다

## 3주차 — 레이어 세기와 빈곳 지목

**배울 것**: 곡은 보통 4~6겹(드럼/베이스/반주/패드/멜로디/장식). "비었다"는 느낌 = 겹이 부족하거나 대역(저·중·고)이 비어 있다는 뜻
**과제**: Dawn FM 아무 곡이나 30초 단위로 "지금 몇 겹인가" 세면서 청취 (정답 필요 없음, 세는 행위가 훈련)
**명령 실습**: 기존 곡에서 빈 구간을 지목해 채우기 의뢰 ("2절 뒤가 허전한데 뭔가 길게 깔리는 게 있으면 좋겠다" — 스트링/패드 선택은 에이전트가 제안)
**합격선**: "풍성하게"라는 말 대신 "어느 구간이, 몇 겹에서, 뭐가 빠진 느낌인지" 말할 수 있다

## 4주차 — 레퍼런스 명령법 (이론 없이 최상급 명령)

**배울 것**: 레퍼런스 지목 3형식
1. 곡 전체: "이 곡 같은 분위기로"
2. **타임스탬프**: "이 곡 1:05~1:20의 그 느낌" ← 가장 강력하고 이론 지식 0 필요
3. 요소 지정: "이 곡의 드럼 + 저 곡의 피아노"
**과제**: 좋아하는 곡에서 "훔치고 싶은 15초"를 3개 수집 (곡명+타임스탬프+뭐가 좋은지 한 줄)
**명령 실습**: 수집한 레퍼런스로 신곡 1개 의뢰 — 에이전트가 스펙으로 번역해 보여주면 승인/수정. 이 왕복 자체가 이론 어휘를 자연 습득시키는 통로 (번역문에서 용어를 주워가면 됨)
**합격선**: 친구 도움 없이 신곡 의뢰 1건을 원샷으로 성공

## 부록 (선택 심화, 서두르지 않음)

- 화성 어휘: 진행에 이름이 있다는 것만 인지 (王道진행, 캐논 등). 필요해지면 그때 — 레퍼런스 지목이 항상 유효한 대체재
- 믹스 어휘: dB, 마스킹, 리미터 — 4주차 이후 자연스럽게

## 상시 치트시트 — 명령 3형식 (이론 불필요 버전)

| 형식 | 최소 템플릿 |
|---|---|
| **신곡 의뢰** | 분위기 한 줄 + 레퍼런스 곡(타임스탬프면 더 좋음) + 빠르기 감 + 원하는 악기 아무거나 → 나머지는 에이전트가 스펙으로 번역해 확인받음 |
| **수정 지시** | 번호 열거, 하나에 하나씩 ("1. 드럼 어쿠스틱으로 2. 베이스 줄여") |
| **피드백** | 관측 → (추정) → 지시. 부위 단어 6개 활용. 형용사 단독 금지 |

## 안티패턴 (세션 실측)

- ❌ 수량만 있는 의뢰 ("N개 만들어줘") → 시스템 기본값 클론이 나온다
- ❌ 형용사 단독 ("밋밋해") → 해석 도박. 최소한 "무엇이"를 붙일 것
- ❌ 여러 문제를 한 문장에 → 번호로 쪼개면 전부 반영된다
- ✅ 모르면 레퍼런스로 지목 — 언제나 유효한 명령이다
