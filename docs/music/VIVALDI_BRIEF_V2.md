## 1. 데이터

`docs/music/tools/vivaldi_data.py` 의 `MOVEMENTS[(season, n)]` 에 12악장 5성부(solo, violin1, violin2, viola, cello)의 전곡 노트가 있습니다(PPQ 480, `(틱, 길이, 피치)`).
- 조성은 `key_name` 이 기준입니다(MIDI `ks` 의 minor 플래그는 신뢰하지 않습니다).
- 박자 변화는 `ts_events`, 피크업은 `pickup` 에 있습니다. `bar_tick(key, bar)` 는 피크업과 박자 변화를 반영한 다운비트 틱을 줍니다.
- `theme_notes(key, part, pad_bars)` 는 첫 다운비트를 0틱으로 맞춘 노트를 줍니다. 피크업은 **음수 틱**이므로 SMF 에 넣기 전에 옮기거나 잘라냅니다.
- 노트가 없는 성부는 빈 리스트입니다(Spring II cello).
- 출처는 Mutopia Project 이고, 이 프로젝트는 **CC BY-SA 3.0** 을 전제합니다. 작품 자체는 퍼블릭 도메인입니다. **모든 MIDI 에 출처를 메타 이벤트(저작권 또는 텍스트)로 넣습니다.** v1 에서는 한 모델의 MIDI 12개에 이 표기가 빠졌습니다.

## 2. Suno 통과 규칙 (캐논 라운드 실측, MUST)

캐논 v1 은 "matches an existing recording" 으로 **차단**됐고, v2·v3a/b/c 는 통과했습니다. 차단을 가른 것은 화성이 아니라 **선율 원리듬 전곡 유지와 모방 성부**였습니다.

1. **원곡 성부를 그대로 겹쳐 쓰지 않습니다.** 주제는 한 성부만 가져옵니다. 모방·카논·원곡 성부 더블링은 금지입니다.
2. **리듬을 바꿉니다.** 음고 윤곽은 살리되 다음 중 둘 이상을 씁니다: ① 부분 당김 ② 음가 2배/반 ③ 빠른 런을 골격음만 남기기 ④ 스윙이나 셔플 같은 박 분할 변경. 원리듬 그대로인 구간은 **연속 4마디 이하**로 둡니다.
3. **박자나 템포를 옮깁니다.** 원본 BPM 대비 ±15% 이상 바꾸거나 하프/더블타임으로 갑니다. 3/8·12/8 악장은 박자도 다른 박자로 다시 묶습니다.
4. **원곡 베이스 라인을 그대로 깔지 않습니다.** 화성은 새로 짭니다. 조옮김도 허용합니다.
5. **주제는 전체의 40~60% 입니다.** 나머지는 자작 소재(모티프, 전주·간주·후주, 전개)로 채웁니다. 듣는 사람이 "아, 사계"를 알아채되 Suno 필터는 지나가는 지점이 목표입니다.
6. 업로드가 차단되면 ② 리듬 변형 비율을 높이고 ⑤ 주제 비율을 낮춘 다음 판을 만듭니다. 차단과 통과 결과는 반드시 기록합니다.

## 3. 장르·편성 (MUST)

- **장르**: 모델이 악장마다 자유롭게 고릅니다. 장르 수나 다양성 할당량은 없습니다.
- **배제 장르**: 라운드 킥오프의 `배제 장르:` 줄에 적힌 장르만 피합니다. 그 줄이 없거나 비어 있으면 제한이 없습니다.
- **계획 파일**: 작곡 전에 `docs/music/vivaldi_<model>_v2_plan.md` 를 쓰고 자기 브랜치에 커밋합니다. 악장별로 다음을 적습니다.
  - 장르
  - 그 장르를 고른 이유. 원곡 악장의 성격(템포, 박자, 표제, 질감)에서 나온 이유여야 합니다.
  - 편성: 트랙 이름과 PC
  - 박자·BPM·마디 수
- **악기**: `PROMPT_GUIDELINES.md` §4 표에 있는 PC 만 씁니다. 표에 없는 PC 는 쓰기 전에 Logic 믹서 스트립에서 실제로 로드되는 패치를 실측하고 표에 추가합니다.
- **박자**: 4/4 가 아닌 박자로 쓰려면 SMF 의 박자 메타가 그 박자여야 합니다. 이 브랜치의 `pipeline.build_smf` 는 4/4 만 씁니다. band-fable `7d6d9a0` 에 `timesig`·`tempos` 인자를 더한 확장이 있으니, 이것을 들여온 뒤에 씁니다.
- **길이**: 약 3분입니다(Suno Cover 3분 입력 실측 통과 범위).
- **마커**: 구간 마커를 반드시 넣습니다.
- **점검 줄**: 곡마다 원리듬 최장 연속 마디, 주제 비율, 트랙별 벨로시티 범위, 트랙별 음/마디, 마지막 노트 위치를 출력합니다.
- **밀도 하한**: 미정입니다(사용자 결정 대기). v1 청취 판정은 "디테일 부족, 빈 공간 많음"이었습니다.

## 4. 산출물 (세션당 12곡)

- **계획**: `docs/music/vivaldi_<model>_v2_plan.md` (먼저 커밋)
- **작곡기**: `docs/music/tools/vivaldi_<model>_v2.py`
  - `SKETCHES` 12개: key, sid, title, genre, genre_reason, meter, bpm, bars, tracks, theme_part, theme_window, rhythm_ops, notes
  - `compose(sid)` 와 `__main__` 이 `{sid}-v2.mid` 12개를 쓰고 점검 줄을 출력합니다.
  - `--check` 는 파일을 쓰지 않고 재생성 바이트와 디스크 MIDI 를 비교합니다.
- **이름**: sid 는 `vs-<season><n>-<model>`, title 은 `<Season> <I/II/III> <Model>`, 판 표기는 `v2` 입니다. 모델 접미사가 없으면 공용 폴더에서 서로 덮어씁니다.
- **바운스**: `pipeline.produce(sid, title, 'v2', mid)` 를 순차 호출합니다. Logic 은 한 대뿐이라 `produce()` 가 세션 간 잠금(`/Volumes/Netac 2TB/music/.logic-lock`)을 잡습니다. `TimeoutError` 가 난 곡은 "대기 초과"로 기록하고 다음 곡으로 넘어갑니다.
- **Suno**: `docs/music/suno/vivaldi_<model>_v2.md` 에 12블록 `## {sid}-v2` 를 씁니다.
  - Style 은 300자 이하, Description 은 **1,000자 이하(공백 포함)** 이며, `len()` 측정 결과를 출력합니다.
  - Description 에는 "variation on the theme of Vivaldi's Four Seasons, <Season> <mvt>" 를 넣고, 원곡 제목은 Style 에 넣지 않습니다.
- **기록**: `docs/music/FEEDBACK_LOG.md` 끝에 `## <날짜> Vivaldi 사계 변주 v2 — <model> (<모델 ID>)` 절을 둡니다.
  - 표 열: `| key | sid | 장르 | 장르 이유 | 박자 | BPM | 마디 | 편성 | 주제 창 | 리듬 변형 | 주제 비율 | 업로드 결과 |`
  - 표 아래에 계획 대비 달라진 점을 적습니다.
- **세션 요약**: `docs/sum/session_<날짜>_vivaldi-v2-<model>.md` 에 과정·결정·실패·결과를 적고 모델 ID 를 명시합니다.
- **커밋**: 자기 브랜치에만 합니다.
