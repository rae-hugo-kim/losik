# 곡 제작 프롬프트 — "Night Circuit" (가제)

> 다음 사이클(Logic Pro MCP 제작)의 입력 스펙. 이 문서 하나로 트랙 생성·미디 작성·믹스 방향까지 결정 가능해야 한다.

## 1. 콘셉트

- **한 줄**: 자정 넘은 도시 고속도로를 달리는 야간 드라이브 — 몽환적이지만 추진력 있는 레트로 신스웨이브.
- **레퍼런스 감성**: Kavinsky "Nightcall"의 어두운 무게감 + The Midnight의 멜로딕한 따뜻함 (모방 아님, 방향 지표).

## 2. 기본 파라미터

| 항목 | 값 |
|---|---|
| 장르 | 신스웨이브 / 레트로 일렉트로닉 |
| 형식 | 인스트루멘털 |
| BPM | 110 |
| 박자 | 4/4 |
| 키 | C minor |
| 길이 | 96마디 ≈ 3분 29초 |
| 메인 진행 | i–VI–III–VII (Cm–A♭–E♭–B♭) |
| 브릿지 진행 | iv–i–VI–V (Fm–Cm–A♭–G) — 하모닉 마이너 차용으로 긴장 |

## 3. 곡 구성 (96마디)

| 섹션 | 마디 | 길이 | 내용 |
|---|---|---|---|
| Intro | 1–8 | 8 | 패드 + 필터 닫힌 아르페지오. 드럼 없음 → 7–8마디 필인 |
| Verse A | 9–24 | 16 | 킥+베이스 진입. 아르페지오 필터 서서히 개방. 미니멀 |
| Pre | 25–32 | 8 | 스네어 빌드, 라이저, 리드 모티프 예고(단편) |
| Chorus 1 | 33–48 | 16 | 리드 멜로디 풀 등장. 전 트랙 합주. 사이드체인 펌핑 최대 |
| Verse B | 49–56 | 8 | 드럼 절반 덜어냄. 리드 → 옥타브 아래 카운터 멜로디 |
| Chorus 2 | 57–72 | 16 | Chorus 1 + 백그라운드 아르페지오 옥타브 상행 레이어 |

| Outro | 89–96 | 8 | 요소 역순 제거 → 인트로 아르페지오만 남기고 필터 클로즈 |

## 4. 사운드 팔레트 (Logic Pro 스톡 기준, 트랙 7개)

1. **Drums** — Drum Machine Designer, 80s 계열 킷 (LinnDrum/808 느낌). 게이트 리버브 스네어.
2. **Bass** — Retro Synth (Analog), 모노 톱니파 베이스. 8분음표 드라이빙 패턴, 루트 중심.
3. **Arp** — Retro Synth 플럭, 16분 아르페지오 (Cm 펜타 기반). 필터 컷오프 자동화가 곡 전체 서사.
4. **Pad** — Alchemy 아날로그 스트링 패드. 화이트노트 롱 코드, 코러스/리버브 깊게.
5. **Lead** — Retro Synth 듀얼 톱니파 + 유니즌, 포르타멘토 약간. 코러스 멜로디 담당.
6. **Counter/Keys** — 일렉트릭 피아노(FM) 또는 폴리신스 스태브, Verse B·브릿지 보조.
7. **FX** — 라이저/임팩트/역방향 심벌. 섹션 전환부 전용.

## 5. 믹스/공간 방향

- 킥·베이스 = 사이드체인 펌핑이 장르 시그니처 — 베이스·패드·아르페지오에 킥 트리거 덕킹.
- 리버브: 스네어(게이트), 리드(플레이트 중간), 패드(홀 길게). 베이스는 드라이.
- 전체 톤: 로우 단단, 하이는 테이프 느낌으로 약간 눌러줌.
